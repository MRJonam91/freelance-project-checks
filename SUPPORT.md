# Support / Supporto

For a reproducible problem, open an issue with the tool version, operating system, Python version, command, error text and a minimal synthetic JSON example. Explain the expected result. Replace private filenames, source text and project figures before sharing. Read [SECURITY.md](SECURITY.md) for vulnerabilities.

Support is best-effort, without a service-level agreement. Donations do not purchase a response time, consulting, extra rights or access to a separate product. This project checks supplied project scenarios; accounting/tax advice and decisions about real client commitments need the appropriate professional/user judgment.

Per problemi riproducibili apri una issue con versione, sistema, Python, comando, errore ed esempio JSON sintetico minimo; indica il risultato atteso. Sostituisci dati privati prima di inviare. Le vulnerabilità seguono [SECURITY.md](SECURITY.md). Supporto secondo disponibilità, senza SLA. Le donazioni non acquistano tempi di risposta, consulenza, diritti aggiuntivi o accesso a prodotti separati. Il tool verifica scenari sui numeri forniti; decisioni cliente e trattamento fiscale/contabile richiedono giudizio adeguato.
